# ATLite 排障

最近构建为 0.3.14；真机未通过验收。见 [最新反馈](DEVICE_DEBUG_2026-10-31.md)。

- 安装后重启桌面，核对插件日志实际版本。目录缺失也可能是路径/权限或初始化失败，目录存在也不能证明注入。
- App 探针是普通 mobile 权限进程；它的抓屏失败不能代替 SpringBoard 结果。P2 请求已提交不等于插件已执行。

- 日志页应看到 实际安装版本和 SpringBoard 载入信息；ready只表示符号/客户端初始化，不等于触摸或画面已验证。
- 邮箱没有输入：先确认焦点和US键盘事件被目标App接受；普通邮箱ASCII范围内才支持。默认示例预留5秒切换App；没有填坐标不会自动猜输入框。
- OCR没有用户名：示例仅匹配“用户名：”或“Username:”，按实际页面修改规则；不要把邮箱前缀当识别结果。
- 查询任务409：旧任务pending/processing尚未完成，先查看当前jobId；需要重置时DELETE对应jobId。它只取消记录，脚本仍须手机停止按钮。
- 查询404：没有任务，或传了已被替换的jobId。当前只保留最近一个任务。
- 电脑访问超时：确保同一可信局域网、App处于有运行机会的前台。退后台iOS可能挂起HTTP服务；先回前台再取结果。
- 搜图超时：大模板/全屏搜索超过2秒会明确报错。先裁小模板、确认分辨率；本轮未引入复杂视觉框架。
- 停止无立即响应：合作取消在Lua、分片sleep和NCC检查；同步Vision/系统IPC仍需返回。不能承诺同进程强停，这是A/B独立引擎下一步要处理的边界。
- 探针NOT-ROOT是预期：此版默认去掉setuid，防止特权路径写入。App输出保存probe-app.log；SpringBoard的P2看tweak.log，不以begin行判完成。Framebuffer服务发现未实现，不能据此判断权限不足。

反馈请给：设备/iOS/roothide版本、完整日志、jobId与状态、目标页面布局和OCR输出。不要仅凭PASS字符串判断全链路成功。
