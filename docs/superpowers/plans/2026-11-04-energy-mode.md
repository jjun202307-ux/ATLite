# 默认节能模式实施计划

用户已授权实施；保留取消勾选后的原识别路径。不改变识别阈值、键盘间隔、重试和账号规则。

1. 增加手机列表页“节能模式”勾选项，首次默认开启，持久保存；每次脚本开始读取一次，下次运行生效。
2. 增加显式 withScreen 读取范围：范围内共享截图和成功 OCR 结果；点击、按键、等待立即失效；范围退出、异常、停止及脚本结束清理。
3. 节能模式缓存模板解码，文件内容变化后重新解码；取消勾选仍逐次加载。缓存仅在本次脚本存在。
4. 完整流程每个现有流程片段接入读取范围；旧版运行器缺少接口时照常执行。
5. 增加开关、范围返回值/异常、截图复用与失效、模板更新测试。执行原有回归与构建检查。
6. 真机分别验证开/关、连续读图、OCR 复用、输入/等待后刷新及停止。未执行的测试明确记录。
7. 发布新 deb、脚本和使用说明。降低的调用次数可测，实际温度降幅须实测，不能以推测代替。

第一版不改 OCR 语言、准确模式、跨进程协议、代理与业务流程，不增加任务限制。
