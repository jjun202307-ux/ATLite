# 节能模式

ATLite 0.3.36 在手机脚本列表上方增加“节能模式”勾选项。首次默认勾选；选择会保存在手机，每次开始脚本时读取。运行中修改，在下次运行生效。

- 勾选：完整流程在同一段连续读取中复用截图、成功的 OCR 结果，并缓存模板解码。
- 取消勾选：回到原有逐次截图、逐次 OCR、逐次解码模板的路径。

点击、按键、文字输入或等待都会使当前截图和 OCR 缓存失效；下一次识别重新截图。读取范围结束、脚本异常、停止或结束时释放截图。模板缓存最多占约 8 MiB 数据，超出时淘汰旧项；大模板仍可识别，只是不缓存。替换模板图片后按新内容加载。

找图阈值、OCR 文本匹配阈值、打字间隔、重试及账号状态规则均不因开关变化。不新增常驻服务。

自己编写脚本时，可把同一画面的连续读取放在一起：

```lua
withScreen(function()
    local a = getColor(100, 200)
    local b = getColor(110, 200)
    local words = ocrText()
    local title = findText("标题") -- 同画面复用上面的 OCR
end)
```

已有脚本不使用 `withScreen` 也能照常运行；节能模式仍可缓存模板。完整流程已接入读取范围。关闭节能模式时，`withScreen` 仍执行函数，但不复用截图或 OCR。

日志开头记录 `energy mode=ON` 或 `OFF (legacy)`；节能运行结束记录截图、OCR 请求和模板解码次数及复用次数。调用减少不等于已经测得温度降幅；实际发热还受亮度、充电、网络、代理和目标应用影响。
